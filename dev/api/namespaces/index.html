Namespaces

Namespace management for working with RDF vocabularies.

Types and Functions

RDFLib.Namespace — Type
Namespace(uri::AbstractString)

An RDF namespace. Generates URIRef terms by appending local names.

Examples

EX = Namespace("http://example.org/")
EX("Person")  # URIRef("http://example.org/Person")
source
RDFLib.DefinedNamespace — Type
DefinedNamespace

A namespace with an enumerated set of allowed terms (like rdflib's DefinedNamespace). Accessing an undefined term throws an error.

Constructed internally; use the predefined RDF, RDFS, XSD, OWL constants.

source
RDFLib.NamespaceManager — Type
NamespaceManager()

Manages prefix ↔ namespace URI bindings.

Examples

nsm = NamespaceManager()
bind!(nsm, "ex", Namespace("http://example.org/"))
expand_curie(nsm, "ex:Person")  # URIRef("http://example.org/Person")
source

expand_curie(nsm, curie) -> URIRef

RDFLib.compute_qname — Function
compute_qname(nsm, uri) -> (prefix, namespace, localname)

Split a URI into prefix, namespace, and local name. Auto-binds unknown namespaces as ns1, ns2, etc.

source
RDFLib.create_namespace — Function
create_namespace(g::RDFGraph, ns_uri::AbstractString, name::AbstractString) -> String

Generate Julia source code for a DefinedNamespace from an ontology graph. Scans all triples for URIRefs starting with ns_uri and extracts local names.

Returns a string of Julia code defining a const DefinedNamespace.

source

Predefined Namespaces

The following standard namespaces are available: RDF, RDFS, XSD, OWL, SKOS, FOAF, DC, DCTERMS, DCAT, PROV, SDO, SH, VANN, VOID, DOAP, ORG, GEO, GEOF, BRICK, CSVW, DCAM, DCMITYPE, ODRL2, PROF, QB, SOSA, SSN, TIME, WGS.
