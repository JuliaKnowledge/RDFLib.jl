Terms

RDF terms are the building blocks of RDF data: URIs, blank nodes, literals, and variables.

Types

RDFLib.Identifier — Type
Identifier

Abstract supertype for all RDF identifiers (URIs, blank nodes, literals, variables).

source
RDFLib.Node — Type
Node <: Identifier

Abstract type for RDF nodes that can appear as subjects in triples.

source
RDFLib.IdentifiedNode — Type
IdentifiedNode <: Node

Abstract type for nodes with identity (URIRef and BNode).

source
RDFLib.URIRef — Type
URIRef(uri::AbstractString)

An RDF URI reference. Immutable wrapper around a URI string.

Examples

u = URIRef("http://example.org/resource")
n3(u)  # "<http://example.org/resource>"
source
RDFLib.BNode — Type
BNode()
BNode(id::AbstractString)

An RDF blank node. Auto-generates a unique identifier if none provided.

Examples

b = BNode()
n3(b)  # "_:N<hex>"
source
RDFLib.Literal — Type
Literal(value; datatype=nothing, lang=nothing)
Literal(value::Number)
Literal(value::Bool)
Literal(value::DateTime)

An RDF literal value with optional datatype URI or language tag.

Language tags and datatypes are mutually exclusive (per RDF spec, a language-tagged literal implicitly has datatype rdf:langString).

Examples

Literal("hello")
Literal("bonjour", lang="fr")
Literal(42)                        # auto-typed as xsd:integer
Literal("3.14", datatype=URIRef("http://www.w3.org/2001/XMLSchema#decimal"))
source
RDFLib.Variable — Type
Variable(name::AbstractString)

A SPARQL/N3 variable (e.g., ?x).

source
RDFLib.Triple — Type
Triple

An RDF triple (subject, predicate, object). Subject must be a Node (URIRef or BNode), predicate must be a URIRef, object can be any Identifier.

source

RDFLib.from_n3 — Function
from_n3(s::AbstractString) -> Identifier

Parse an N3 notation string into an RDF term.

Supported formats:

  • <http://example.org/x> → URIRef
  • _:b1 → BNode
  • "hello" → Literal (plain)
  • "hello"@en → Literal with language tag
  • "42"^^<http://www.w3.org/2001/XMLSchema#integer> → Literal with datatype
  • "true"^^xsd:boolean → Literal with common prefix datatype
source
