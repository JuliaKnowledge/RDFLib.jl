Graph

The core RDFGraph type and operations for adding, removing, and querying triples.

RDFGraph

RDFLib.RDFGraph — Type
RDFGraph(; store=MemoryStore(), identifier=nothing)

An RDF graph backed by a store.

Examples

g = RDFGraph()
add!(g, Triple(URIRef("http://example.org/s"), URIRef("http://example.org/p"), Literal("hello")))
length(g)  # 1
for triple in g
    println(triple)
end

Dataset (Named Graphs)

RDFLib.Dataset — Type
Dataset()

An RDF Dataset: a default graph plus zero or more named graphs.

Examples

ds = Dataset()
add!(ds, Triple(EX("s"), EX("p"), EX("o")))  # adds to default graph
add!(ds, Triple(EX("s"), EX("p2"), EX("o2")), EX("graph1"))  # named graph

for q in quads(ds)
    println(q)
end

Resource

RDFLib.Resource — Type
Resource(g::RDFGraph, identifier::IdentifiedNode)

An object-oriented view of a node in an RDF graph. Provides convenient property-style access to the node's predicates and objects.

Examples

g = RDFGraph()
EX = Namespace("http://example.org/")
add!(g, Triple(EX("alice"), RDFS.label, Literal("Alice")))
add!(g, Triple(EX("alice"), EX("age"), Literal(30)))

r = Resource(g, EX("alice"))
r[RDFS.label]           # Literal("Alice") — single value
collect(r[EX("knows")])  # all values for a predicate (when using iteration)

Graph Wrappers

RDFLib.ConjunctiveGraph — Type
ConjunctiveGraph(; identifier=nothing)

A multi-context graph that spans all named graphs in a Dataset. Provides a unified view over all triples across all contexts.

Examples

cg = ConjunctiveGraph()
EX = Namespace("http://example.org/")
add!(cg, Triple(EX("s"), EX("p"), EX("o")))
add!(cg, Triple(EX("s2"), EX("p2"), EX("o2")), EX("g1"))
length(cg)  # 2

RDFLib.ReadOnlyGraphAggregate — Type
ReadOnlyGraphAggregate(graphs::Vector{<:RDFGraph})

A read-only aggregate view over multiple RDF graphs. Queries search all constituent graphs. Mutation operations throw an error.

Examples

g1, g2 = RDFGraph(), RDFGraph()
EX = Namespace("http://example.org/")
add!(g1, Triple(EX("a"), EX("p"), EX("b")))
add!(g2, Triple(EX("c"), EX("p"), EX("d")))
agg = ReadOnlyGraphAggregate([g1, g2])
length(agg)  # 2
source
RDFLib.BatchAddGraph — Type
BatchAddGraph(g::RDFGraph; batch_size=1000)

Wrap a graph for optimized bulk insertion. Triples are buffered and flushed to the underlying graph when the buffer reaches batch_size.

Examples

g = RDFGraph()
bag = BatchAddGraph(g; batch_size=100)
EX = Namespace("http://example.org/")
for i in 1:250
    add!(bag, Triple(EX("s$i"), EX("p"), EX("o$i")))
end
close!(bag)  # flush remaining
length(g)    # 250
source

RDFLib.IsomorphicGraph — Type
IsomorphicGraph(g::RDFGraph)

Wrap an RDFGraph so that == and hash use graph isomorphism. Two IsomorphicGraphs are equal if and only if their underlying graphs are isomorphic (identical up to blank node relabeling).

Examples

g1, g2 = RDFGraph(), RDFGraph()
EX = Namespace("http://example.org/")
add!(g1, Triple(EX("s"), EX("p"), BNode("a")))
add!(g2, Triple(EX("s"), EX("p"), BNode("z")))
IsomorphicGraph(g1) == IsomorphicGraph(g2)  # true
source
