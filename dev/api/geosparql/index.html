RDFLib.geo_relate — Function
geo_relate(a::AbstractGeometry, b::AbstractGeometry) → String

Compute the DE-9IM intersection matrix as a 9-character string. Characters: 'F' (empty), '0' (point), '1' (line), '2' (area). Matrix order: II, IB, IE, BI, BB, BE, EI, EB, EE

source
geo_relate(a::AbstractGeometry, b::AbstractGeometry, pattern::String) → Bool

Test if the DE-9IM matrix of a and b matches the given pattern. Pattern characters: 'T' (any non-F), 'F' (empty), '*' (any), '0', '1', '2'.
