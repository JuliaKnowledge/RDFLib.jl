Serialization

Reading and writing RDF data in multiple formats.

Core API

RDFLib.SerializationFormat — Type
SerializationFormat

Abstract type for RDF serialization formats. Dispatch on format types instead of rdflib's plugin registry.

source
RDFLib.serialize — Function
serialize(io::IO, g::RDFGraph, format::SerializationFormat)

Serialize a graph to an IO stream in the given format.

Examples

g = RDFGraph()
add!(g, Triple(URIRef("http://example.org/s"), URIRef("http://example.org/p"), Literal("hello")))
io = IOBuffer()
serialize(io, g, NTriplesFormat())
source
serialize(g::RDFGraph, format::SerializationFormat=NTriplesFormat()) -> String

Serialize a graph to a string in the given format. Defaults to N-Triples.

Examples

g = RDFGraph()
add!(g, Triple(URIRef("http://example.org/s"), URIRef("http://example.org/p"), Literal("hello")))
str = serialize(g)                    # N-Triples (default)
str = serialize(g, TurtleFormat())    # Turtle format
source

Serialize a graph to a file. The format must be specified explicitly.

Examples

RDFLib.parse_rdf — Function
parse_rdf(source, format::SerializationFormat=NTriplesFormat()) -> RDFGraph

Parse RDF from source (IO stream or string) into a new graph. Defaults to N-Triples.

Examples

g = parse_rdf("""<http://example.org/s> <http://example.org/p> "hello" .\n""", NTriplesFormat())
g = parse_rdf(open("data.ttl"), TurtleFormat())
source
parse_rdf(filename::AbstractString) -> RDFGraph

Parse RDF from a file, auto-detecting the format from the file extension.

Supported extensions: .nt, .ttl, .nq, .rdf/.xml, .trig, .jsonld/.json.

Examples

g = parse_rdf("data.ttl")   # auto-detects Turtle
g = parse_rdf("data.nt")    # auto-detects N-Triples

RDFLib.load_rdf — Function
load_rdf(url::AbstractString; format=nothing) -> RDFGraph

Load an RDF graph from a URL with automatic content negotiation.

If format is not specified, the format is determined from the server's Content-Type response header, falling back to URL extension detection.

Examples

g = load_rdf("http://example.org/data.ttl")
g = load_rdf("http://example.org/data", format=TurtleFormat())
source

Parse N-Triples from an IO stream in chunks, yielding triples through a Channel.

Example

RDFLib.parse_sparql_results_csv — Function
parse_sparql_results_csv(csv_str::AbstractString)

Parse a SPARQL Results CSV string into (variables, results).

CSV format is lossy: URIs appear as bare strings, blank nodes as _:id, and literals as plain values. This parser heuristically reconstructs types: values starting with http:// or https:// → URIRef, _: → BNode, otherwise → Literal.

source
RDFLib.parse_sparql_results_tsv — Function
parse_sparql_results_tsv(tsv_str::AbstractString)

Parse a SPARQL Results TSV string into (variables, results).

TSV format preserves term types: URIs as <uri>, blank nodes as _:id, literals in N3 notation ("value"@lang or "value"^^<datatype>).
